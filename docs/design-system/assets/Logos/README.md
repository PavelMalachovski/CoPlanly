CoPlanly's mark is the launcher icon's glyph: a calendar with binder rings, a header bar and a 3 × 3 grid of day dots, converted path for path from `res/mipmap/ic_launcher_foreground.xml`.

- `coplanly-app-icon.svg` — the full app icon: the white glyph on `primary` (#4F46E5), as the launcher and the system splash draw it. Square; the launcher applies its own mask.
- `coplanly-mark-indigo.svg` — the glyph alone in `primary` (#4F46E5), for light grounds.
- `coplanly-mark-white.svg` — the glyph alone in white, for `primary` or dark grounds.

Single-ink files: their ink is fixed in the file (they are drawn through `<img>` and cannot inherit a colour). There is no wordmark file: set "CoPlanly" in Onest Bold beside the mark. Never recolour the mark in a parent's colour — pink and blue identify people, not the product.
