# CI speed (the iPhone half) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a pull request's CI in well under an hour by building the Firebase pods once per spec,
splitting `ios-app` into parallel jobs, running the iPhone tours only when the screens change, and
gating the macOS jobs on drafts.

**Architecture:** `tools/ci-changes.js` gains an `ios_tour` output; `shared-data/build.gradle.kts`
gains a `coplanly.prebuiltPods` switch; `.github/workflows/ci.yml` replaces `ios-app` with five jobs
that share the build through one tarred artifact.

**Tech Stack:** GitHub Actions, Node (`node --test`), Gradle Kotlin DSL, Xcode `xcodebuild`.

**Spec:** `docs/superpowers/specs/2026-11-23-ci-speed-design.md`

## Global Constraints

- Owner decisions, 23 November 2026: tours run when a PR touches what they show (and always on
  `main`); drafts run the macOS jobs only with `full-ci`.
- A skipped check reads as skipped; a job that ran no tests publishes no green check
  (`require_tests: true` stays).
- No secret in any iPhone job; nothing reaches a real Firebase project.
- The pods cache key is unchanged: `pods-<os>-<arch>-<xcode>-<podspec hash>`.

## Review Focus

1. A cache restored by a **prefix** (near miss) must never set `prebuiltPods`: pods from another
   spec would be linked. Only `cache-hit == 'true'`.
2. Build products moved between jobs lose executable bits through `upload-artifact`: tar them.
3. A PR changing only `shared-data/` (data layer) must not run the tours; one changing
   `shared-ui/.../presentation/` or `composeResources/` must.
4. `report` must `need` every new job, or its row reads "in progress".
5. The emulator tests need a booted simulator (`COPLANLY_SIMULATOR_UDID`) without the app's build.

**Files:** Modify `tools/ci-changes.js`; Test `tools/test/ci-changes.test.js`.

**Interfaces:** Produces `decide(paths).iosTour: boolean`, printed as `ios_tour=` by `format`;
`everything().iosTour === true`, `nothing().iosTour === false`.

- [ ] Tests: `the iPhone tours run when a screen, a string or the iPhone app changes` —
  `decide(['shared-ui/src/commonMain/kotlin/com/coparently/app/presentation/home/HomeScreen.kt']).iosTour`,
  `…composeResources/values/home_strings.xml`, `iosApp/project.yml`,
  `tools/ios/seed-shell-family.js`, `.github/workflows/ci.yml` are true;
  `the iPhone tours skip a data, server, Android or push test change` —
  `shared-data/src/commonMain/kotlin/com/coparently/app/data/sync/SyncService.kt`,
  `functions/index.js`, `app/src/main/AndroidManifest.xml`,
  `iosApp/CoPlanlyUITests/PushUITests.swift` are false; `format` lists `ios_tour` last.
- [ ] `node --test tools/test/ci-changes.test.js` fails.
- [ ] Implement `IOS_TOUR_INPUTS` (shared-ui composeResources and `presentation/`, `ios/` Kotlin in
  any source set; `iosApp/` but `CoPlanlyUITests/PushUITests.swift`; `tools/ios/seed-shell-family.js`,
  `tools/ios/known-tour-crash.py`) and `iosTour = ios && (realBuild || kept.some(IOS_TOUR_INPUTS))`,

### Task 2: `coplanly.prebuiltPods`

**Files:** Modify `shared-data/build.gradle.kts`.

- [ ] Disable every task of `:shared-data` named `podGen*`, `podInstall*`, `podSetupBuild*`,
  `podBuild*`, `podImport` when the Gradle property `coplanly.prebuiltPods` is `true`, with a KDoc
  saying CI passes it only on the pods cache's exact key.
- [ ] `./gradlew :shared-data:tasks -Pcoplanly.prebuiltPods=true` configures (local); commit.

### Task 3: the workflow

**Files:** Modify `.github/workflows/ci.yml`.

- [ ] `shared-ios`: `if` adds `&& needs.changes.outputs.emulators == 'true'`; the link and test steps
  pass `-Pcoplanly.prebuiltPods=true` when `steps.pods.outputs.cache-hit == 'true'`.
- [ ] `changes` exposes `ios_tour`.
- [ ] Replace `ios-app` with `ios-build` (project, SPM restore/save, build-for-testing, launch, tar

  booted simulator, emulator tests + their checks/uploads/check run), `ios-shell`, `ios-tour`,
  `ios-tour-appearance` (each: download + untar products, xcodegen, emulators, its `simulator.sh`
  command, its uploads and its pass/crash check). All iPhone jobs gated on `ios` and `emulators`;
  tours also on `ios_tour`.

- [ ] `actionlint`-style check: `ruby -ryaml -e 'YAML.load_file(".github/workflows/ci.yml")'`.
