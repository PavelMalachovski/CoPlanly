# Meeting 25.11 fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the seven fixes the owner approved after the tester meeting of 25 November 2026.

**Architecture:** Each fix stays inside the screen or the wording it touches:
- Home's avatars, the colour picker, the request history, the school import and the swap sheet are
  Compose changes in `:shared-ui`.
- The swap sentence is a pure function in `:shared` (`domain/custody/SwapSentence.kt`). Both the
  screens (Compose resources) and the push (`:push-wording`) word it.
- The push gains one data field, `childNames`.

**Tech Stack:** Kotlin Multiplatform, Compose Multiplatform 1.9.3, Material 3, Koin, Firestore rules, `:push-wording`.

**Spec:** `docs/superpowers/specs/2026-11-25-meeting-2511-design.md`. The canvas board is `Meeting2511.dc.html`.

## Global Constraints

- **Strings.** Every new user-facing string goes into all five locales (`values`, `-cs`, `-de`,
  `-ru`, `-uk`) under `shared-ui/src/commonMain/composeResources/`, in the feature's existing file.
  - Apostrophe `'`, straight quote `"`.
  - No `%s`/`%d`, only `%1$s`/`%1$d`.
  - No `%%` beside arguments.
  - English sentence case.
  - RU/UK never "опека".
  - `node tools/check-invariants.js` must pass.
- **Names.** Never decline a name in cs/ru/uk: every name stays in the nominative.
- **Theme tokens.** Colours from `MaterialTheme.colorScheme` or `ParentColors` (never raw
  `MomPink`/`DadBlue`, never hex). Paddings are `Spacing` steps, icons `IconSizes`, corners from
  `MaterialTheme.shapes`/`CoPlanlyCorners`. Every icon goes through `AppIcon`, and a new icon gets
  an `SF_SYMBOLS` row (`SfSymbolTableTest`).
- **Parent colour.** A parent's colour identifies a person and is never a status colour. Text in a
  parent colour uses `ParentColors.text`.
- **No-op affordances.** No affordance does nothing (design item 8). An avatar without a viewable
  photo is not a button.
- **KDoc and style.** KDoc on public declarations. Conventional Commits. Commits end with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Build check.** Per task: `./gradlew :shared-ui:testAndroidHostTest :app:testDebugUnitTest` for
  the touched tests, plus `./gradlew :app:assembleDebug detekt`. JDK 17 is at
  `/Library/Java/JavaVirtualMachines/temurin-17.jdk/Contents/Home`.
- **Screenshot baselines.** They are recorded only by the Regenerate workflow: do not commit PNGs
  you record locally. Add screenshot test cases where a task says to.

## Review Focus

1. The colour notice shows for the parent who is **not** moved. It must show only when
   `ParentPalette.of(...)` draws this parent in another colour than the one being picked.
2. A swap with days on one side only ("gives" or "asks") must not print an empty "and with Pavel on"
   clause.
3. A Czech/Russian sentence with two children uses the plural verb ("budou", "будут").
4. An older sender's push with no `childNames` keeps today's text exactly (`PushWordingGoldenTest`).
5. On the Calendar, a tap on an avatar must still toggle the filter, not open a photo.
